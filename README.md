# 📊 Global Retail Sales Dashboard (Power BI)

## 🌍 Project Overview

This project presents a **Global Retail Sales Dashboard** built using **Power BI** to analyze sales performance, profit trends, regional performance, and product insights. The dashboard helps businesses make **data-driven decisions** by transforming raw sales data into clear and interactive visual insights.

---

## 🚀 Dashboard Features

✨ **Key Performance Indicators (KPIs)**

* 💰 **Total Sales:** 9.48M
* 📈 **Total Profit:** 1.09M
* 📊 **Profit Margin:** 11.50%
* 🔄 **Return Rate:** 4.69%

📅 **Monthly Sales Trend**

* Displays sales performance across months to identify **seasonal trends and fluctuations**.

🌎 **Sales by Region**

* Shows regional performance including **Central, South, North, Oceania, Southeast Asia, and North Asia**.

📦 **Top 10 Products by Sales**

* Highlights the **best-performing products** based on total revenue.

📊 **Segment Contribution**

* Shows sales distribution among **Consumer, Corporate, and Home Office segments**.

🎯 **Sales vs Target**

* Visual gauge comparing **actual sales vs sales target**.

📉 **Profit Conditional Formatting**

* Identifies **low-profit or negative-profit products** using visual indicators.

---

## 📌 Interactive Filters

Users can dynamically explore the dashboard using slicers:

🔹 Region
🔹 Segment
🔹 Category
🔹 Order Year

These filters allow deeper insights into specific **sales dimensions**.

## 📊 Key Insights

✔ Consumer segment contributes the **highest sales share**.
✔ Certain products generate **high sales but lower profit margins**.
✔ Regional performance varies significantly, with **Central region leading sales**.
✔ Seasonal trends affect monthly sales performance.
